This site is one of them. Astro with React islands, GSAP for motion, Tailwind for

HTML, CSS, JavaScript, jQuery, Node, Express, PostgreSQL, OAuth — for the same
reason: filling in the parts of the stack that backend work never forces you to
learn properly.
